# Example deployment

A runnable example of the **source/deployment split** (design §5.5): this
directory holds only a `platform.toml` (+ secrets + a generated `platform.lock`)
and produces a self-contained `./platform` binary from the Junius source.

It is **not** a workspace member — it's a sample deployment that happens to live
in-tree. Real deployments live in their own repos and pin a git source.

## Layout

```
platform.toml     # which plugins ship + how they're configured
platform.lock     # generated by `junius build` (gitignored here — see below)
secrets/          # file: secret values mounted at runtime (gitignored)
platform          # the built binary (gitignored)
```

## Validate the config (no build, no database)

```sh
../../target/release/junius build --check-config
```

Resolves `[source]`, then checks every enabled plugin's manifest + the
deployment's config/secrets. The host has the same self-check:

```sh
./platform --check-config --config platform.toml
```

## Build

```sh
# Export the env: secrets the config references, and mount the file: ones:
export OIDC_CLIENT_SECRET=… SESSION_KEY=… ROLE_PW_SECRET=…
export MINIO_USER=minioadmin MINIO_PASS=minioadmin STORAGE_TOKEN_SECRET=…
mkdir -p secrets && printf 'dev-hello-key' > secrets/hello_api_key

../../target/release/junius build          # composes the source, builds ./platform
./platform --config platform.toml          # run it (needs the backing services)
```

`junius build` writes `platform.lock` (the resolved source's blake3 hashes) and
refuses to build if a later run's source no longer matches — rerun with
`--update-lock` when the change is intended.

## Source: local path vs git

This example uses a local path:

```toml
[source]
path = "../.."
```

Building a **local path** source regenerates composition glue *inside that source
tree*, and its `platform.lock` tracks the live (constantly-changing) tree — which
is why the lock is gitignored here. A real deployment pins a **git** source for an
isolated, reproducible build and commits its lock:

```toml
[source]
repo = "git+https://github.com/your-org/junius.git"
rev  = "v1.0.0"
```

## Plugin selection

```sh
../../target/release/junius plugin list
../../target/release/junius plugin disable widgets   # edits platform.toml + re-syncs
../../target/release/junius plugin enable widgets
```
